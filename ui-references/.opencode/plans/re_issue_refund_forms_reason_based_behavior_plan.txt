# Plan: Reason-Based Form Behaviour (Re-Issue & Refund "Payment By" auto-selection)

## Goal
When a user selects a **Reason** in any re-issue/refund form, the **Payment By** field auto-selects a default based on the reason. `default_payment_by` is stored in the `re_issue_refund_reasons` table (nullable — some reasons have no default). Applies to all 4 forms. Payment By starts empty until a reason is chosen.

## Mapping (seeded defaults)
| Reason | reason_of | default_payment_by |
|---|---|---|
| Voluntary Reissue | re-issue | customer |
| Involuntary Reissue | re-issue | airline |
| Schedule Change | re-issue | airline |
| Mistake Reissue | re-issue | employee |
| Sector Change Re-Issue | re-issue | `null` |
| Agent Change | re-issue | `null` |
| Additional Net Fare | re-issue | customer |
| Voluntary Refund | refund | customer |
| Involuntary Refund | refund | airline |
| Mistake Refund | refund | employee |
