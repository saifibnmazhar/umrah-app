# Umrah App — Development Handbook

A guide for developers working on the **Umrah App** Laravel project.

This handbook follows the [Diátaxis Framework](https://diataxis.fr/) for technical
documentation: content is organized by what you need to **do** (tutorial, how-to),
what you need to **understand** (explanation), and what you need to **look up**
(reference).
